# HAOS SMART Monitor

SMART-Werte der Platten am Home-Assistant-Rechner – Weboberfläche und Sensoren, ohne MQTT.

**⚠️ Benötigt ausgeschalteten Schutzmodus und vollen Hardwarezugriff.** Was das bedeutet und was die
App dagegen tut, steht im Abschnitt „Sicherheit“ der README im GitHub-Repository und unter dem Reiter
**Dokumentation**.
